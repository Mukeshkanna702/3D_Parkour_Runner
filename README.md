# 3D Parkour Runner (SkyRush Neon Escape)

A 3D Cyberpunk Parkour Endless Runner application built with Flutter.

## Features
- Dynamic 3D Neon / Cyberpunk aesthetics
- Particle engines & custom shaders
- Clean Architecture + BLoC pattern
